# 🤖 Telegram Bot Yaratish

## 1-Qadam: BotFather bilan bot yaratish

1. Telegramda **@BotFather** ni oching: https://t.me/BotFather

2. `/newbot` kommandasini yuboring

3. Bot nomi kiriting (masalan: **My AI Assistant**)

4. Bot username kiriting (masalan: **my_ai_assistant_bot**)
   - Username `_bot` bilan tugashi kerak
   - Unique bo'lishi kerak

5. BotFather sizga **token** beradi:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz1234567
   ```
   Bu tokenni **saqlang!**

## 2-Qadam: Tokenni menga bering

Tokenni olganingizdan so'ng, menga yuboring va men .env faylga qo'shaman.
