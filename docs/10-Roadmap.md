# 2. Asosiy maqsad

ToDo-BOT loyihasining maqsadi:

Telegram platformasi asosida ishlovchi zamonaviy Task Management tizimini yaratish.

Loyiha quyidagilarni qo'llab-quvvatlashi rejalashtirilgan.

- Shaxsiy vazifalar
- Jamoa vazifalari
- Workspaces
- Kalendar
- Bildirishnomalar
- Fayllar
- Administrator paneli
